## Regra de manutenção

Esta tabela é uma fotografia auditável, não uma promessa de que a fonte concorrente esteja atualizada. Uma nova entrada local só entra quando tiver nome inequívoco, esfera, status e fonte oficial; sinônimos e modalidades do mesmo instituto continuam sob o mesmo `id`. A revisão deve repetir a consulta e registrar a data nesta página.
